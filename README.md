# MAX Web Clone (Тестовое задание GREEN-API)

Реализация пользовательского интерфейса для отправки и получения текстовых сообщений в MAX через сервис GREEN-API.

## Стек технологий
- **React 18** (чистый JavaScript, без избыточного бойлерплейта)
- **Vite** (быстрая сборка)
- **Tailwind CSS** (минималистичный дизайн, похожий на web.max.ru)
- **Lucide React** (современные иконки)

## Инструкция для локального запуска
1. Клонируйте репозиторий: `git clone <ссылка_на_твой_репо>`
2. Перейдите в папку: `cd green-api-max-clone`
3. Установите зависимости: `npm install`
4. Запустите проект: `npm run dev`
5. Откройте в браузере: `http://localhost:5173`

## Реализация требований ТЗ
1. **Авторизация**: Ввод `idInstance` и `apiTokenInstance` (сохраняются в `localStorage`).
2. **Создание чата**: Ввод номера телефона, автоматическое форматирование в `79XXXXXXXXX@c.us`.
3. **Отправка**: POST-запрос на `/sendMessage` строго по спецификации GREEN-API.
4. **Получение**: Long Polling (GET `/receiveNotification` каждые 3 секунды). При получении текстового сообщения оно отрисовывается, и сразу же отправляется DELETE-запрос на `/deleteNotification` для очистки очереди.
5. **Дизайн**: Светлая тема, аккуратные пузыри сообщений (свои справа синие, чужие слева белые), адаптивная верстка.
